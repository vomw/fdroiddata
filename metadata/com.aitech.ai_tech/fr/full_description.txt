AI Tech est un assistant IA conversationnel 100 % sur l'appareil pour
Android. Aucune connexion Internet, aucun cloud, aucun abonnement,
aucun tracker, aucune publicité.

'''Confidentialité radicale''' :
* Permission INTERNET retirée du manifest (tools:node="remove") —
  l'application est techniquement incapable d'envoyer des données.
* ACCESS_NETWORK_STATE également retiré.
* Vérifiable via aapt dump permissions.

'''Modèles supportés (importés par l'utilisateur via SAF)''' :
* Gemma 3 1B int4 — Google Kaggle (~554 Mo, recommandé)
* Qwen, Phi, Llama (.task ou .litertlm)
* Modèles 500 Mo à 4 Go

'''Sécurité''' :
* EncryptedJsonStore<T> : AES-256-GCM avec AAD bindée à l'id objet
* Clé maître scellée Android Keystore via flutter_secure_storage 10.x
* Sanitization prompt anti-injection (12 patterns Llama/ChatML/Gemma)
* RAG sanitization (anti "tu es maintenant", "ignore previous", etc.)
* SHA-256 vérifié à l'import du modèle + bouton "Vérifier" dans Settings
* libOpenCL native lib (accélération GPU via MediaPipe)
* FLAG_SECURE actif

'''Performances''' (Gemma 3 1B int4, indicatives) :
* Samsung S24 FE : ~43 tokens/s
* Samsung S9 : ~9.8 tokens/s
* POCO C75 : ~7.7 tokens/s

'''Mode panique''' : destruction immédiate des chats chiffrés et des
paramètres + désinstallation des modèles importés.

'''Apache 2.0''' — code intégral sur GitHub.
