FTPS Server lets you share files between devices over your local network using the FTPS protocol.

Features:

- User permissions: granular control over read and write access per user
- Per-user root folders: isolated shared directory for each user
- Path security: protection against directory traversal attacks
- UTF-8 support for localized file and folder names
- No ads

Use cases:

- Exchange files between a PC and a laptop over Wi-Fi
- Access PC files from an Android file manager over Wi-Fi
- Access phone files from a desktop FTP client over Wi-Fi

While the server is running, the app keeps the screen awake so Android does not cut off connectivity by locking the device.
