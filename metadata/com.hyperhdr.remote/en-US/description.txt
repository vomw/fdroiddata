Native Android remote control for HyperHDR LED ambilight servers. Control brightness, colors, effects, and monitor your server in real-time — all from your phone with a modern Material 3 interface.

Features:
- Live dashboard with auto-refresh
- RGB color picker with presets
- Effect browser and launcher
- Per-component toggles (LED, grabber, HDR, smoothing)
- Brightness slider
- Home screen widgets (Power, Status, Simple Power)
- Multiple server profiles
- Haptic feedback, edge-to-edge display, animated splash
