Pass Tech est un gestionnaire de mots de passe 100 % local pour Android.
Aucun cloud, aucun compte, aucun serveur, aucun tracker, aucune publicité.

'''Sécurité crypto v4''' :
* Argon2id (m=19 MiB, t=2, p=1 — OWASP 2024)
* AES-256-GCM avec AAD anti-downgrade
* KEK Keystore-bound (StrongBox/TEE)
* HKDF-SHA256 + Random.secure
* Brute-force lockout exponentiel (1, 2, 4, 8, 16 minutes)

'''Confidentialité radicale''' :
* Anti-phishing par domaine (vérification AccessibilityService minimal)
* Coffre leurre anti-coercition (déni plausible avec timing aligné)
* Mode panique : destruction immédiate de la KEK Keystore
* Camouflage launcher (déguisement icône en Calculatrice)
* Héritage post-inactivité (dead-man's switch)
* FLAG_SECURE actif (anti-screenshot)
* Permission INTERNET utilisée uniquement pour vérifier les mises à jour
  via l'API GitHub Releases (anonyme).

'''Open source''' Apache 2.0 — code intégral disponible.
