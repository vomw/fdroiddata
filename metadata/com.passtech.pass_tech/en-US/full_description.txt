Pass Tech is a 100% local password manager for Android. No cloud, no
account, no server, no tracker, no ads.

'''Crypto v4''':
* Argon2id (m=19 MiB, t=2, p=1 — OWASP 2024)
* AES-256-GCM with anti-downgrade AAD
* Keystore-bound KEK (StrongBox/TEE)
* HKDF-SHA256 + Random.secure
* Exponential brute-force lockout (1, 2, 4, 8, 16 minutes)

'''Radical privacy''':
* Domain-based anti-phishing (minimal AccessibilityService verification)
* Decoy vault for anti-coercion (plausible deniability with timing-aligned dummy Argon2id)
* Panic mode: immediate Keystore KEK destruction
* Launcher camouflage (icon disguised as Calculator)
* Post-inactivity heritage (dead-man's switch)
* FLAG_SECURE active (anti-screenshot)
* INTERNET permission used only to check for updates via the GitHub
  Releases API (anonymous).

'''Apache 2.0''' open source — full code available.
