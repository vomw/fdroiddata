NCS SSH Client is an SSH and SFTP client for Android.

Core features (all usable without an account):

* SSH terminal with GPU-accelerated rendering (WebGL) for smooth display
* SFTP file manager: browse directories, copy/delete files, edit text files directly
* Encrypted local storage of hosts, credentials, and command snippets
* Biometric unlock (fingerprint/face recognition)
* SSH key authentication (including ED25519)

Runs entirely locally: On startup you can choose "Continue Without Account" — no connection to any server is made, all data stays encrypted on your device only.

Optional cloud features (require an account with the paid NetCorSoft cloud service):

* Cloud sync of hosts & snippets across multiple devices
* Team collaboration: shared hosts & snippets within a team
* Encrypted credential vault for additional credentials
* Two-factor authentication (2FA) for the cloud account

These features are entirely optional and not required to use the app — without an account, all core features work without any limitation.

No ads. No tracking. No Google Play Services dependency.
