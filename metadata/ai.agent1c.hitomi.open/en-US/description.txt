<p>Open Hitomi is a tiny floating hedgehog companion for Android.</p>
<p>Open Hitomi can:</p>
<ul>
<li>float above your screen as a draggable hedgehog assistant</li>
<li>chat in a compact speech bubble UI</li>
<li>use always-listening speech-to-text mode optionally</li>
<li>open and use a mini Hitomi Browser window for browsing tasks</li>
<li>use a local Ollama-compatible endpoint such as http://127.0.0.1:11434</li>
<li>use optional xAI bring-your-own-key chat in the same connection field</li>
<li>open a mini terminal window overlay for local command transcripts</li>
<li>run optional advanced Linux-like commands through Termux (superuser mode)</li>
<li>monitor Solana chain activity for a user-supplied public wallet address</li>
</ul>
<p>Open Hitomi is not a wallet. It does not store local private keys, does not sign transactions, and does not send transactions.</p>
