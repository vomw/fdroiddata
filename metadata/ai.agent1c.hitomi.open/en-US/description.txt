Open Hitomi is a tiny floating hedgehog companion for Android.

Open Hitomi can:

* Float above your screen as a draggable hedgehog assistant
* Chat in a compact speech bubble UI
* Always-listening speech-to-text mode (optional)
* Open and use a mini "Hitomi Browser" window for browsing tasks
* Use a local Ollama-compatible endpoint such as `http://127.0.0.1:11434`
* Use optional xAI bring-your-own-key chat in the same connection field
* Open a mini terminal window overlay for local command transcripts
* Run optional advanced Linux-like commands through Termux (superuser mode)
* Monitor Solana chain activity for a user-supplied public wallet address

Open Hitomi is not a wallet. It does not store local private keys, does not sign transactions,
and does not send transactions.
